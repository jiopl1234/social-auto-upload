# 14 — 按任务追踪失败证据，同时保护凭据和会话

**What to build:** 使用者能够按任务查看阶段、错误、结果证据与运行版本，而无需泄漏登录凭据；会话更新中断不会破坏可恢复状态。

**Blocked by:** 06 — 任务超时或取消后准时退出，并释放浏览器资源

**Status:** ready-for-agent

**来源:** 《三平台个人账号无人值守发布》规格；用户故事 18、39、40、41、42；代码审计需求 R07、R08。

- [ ] 查询结果关联 job、attempt、阶段、时间、实际元数据、警告及证据引用，能判断是否可能已提交。
- [ ] 机器输出始终可解析，日志不污染 stdout；字段缺失明确为空，不从日志猜平台结果。
- [ ] 验证码、Cookie、登录二维码和带认证 token 的 URL 不进入普通日志或公共诊断；含局部变量的调试输出在生产禁用或经过验证脱敏。
- [ ] 账号会话按本机用户权限和独立目录隔离，更新采用临时写入加原子替换；中断不会覆盖唯一可用会话。
- [ ] 证据有访问范围和保留策略；并发或连续任务的诊断不会写入同一固定文件而互相覆盖。
- [ ] 记录浏览器、驱动和适配能力版本，说明可验证的回退方式；不在本票强制迁移完整 persistent profile。
- [ ] 通过合成秘密、更新中断和连续任务场景，检索输出证明无明文泄漏，且主要业务错误被保留。

**测试边界:** 以已经确认的公共 CLI/任务接口为主；只有平台页面、进程终止和资源回收等必要场景增加本地测试。验收观察结果与交付行为，不绑定私有实现细节。
