# 04 — 发布前验证不可变清单、素材版本和声明事实

**What to build:** 使用者的标题正文、素材、声明及降级策略先形成不可变清单；入队和执行时发现无效或被替换的输入，会返回字段错误且不产生平台提交。

**Blocked by:** 03 — 串行执行任务，同账号只允许一个写入者

**Status:** in-progress

**来源:** 《三平台个人账号无人值守发布》规格；用户故事 6、7、8、9、11、12、13、15；代码审计需求 R02、R05、R11。

- [ ] 内容归属、AI 使用、平台声明和转载来源分别表示；不从原创自动推导 AI 状态，不生成无事实依据的声明默认值。
- [ ] 有效素材在入队时记录摘要与版本，执行前复核；文件被替换、缺失或类型不支持时，返回明确失败且测试目标提交数为 0。
- [ ] 清单包含必需/可选元数据及显式降级策略；未知或超限输入按平台能力拒绝或按显式转换策略处理，不静默截断。
- [ ] 规范化结果不可被后续适配器修改；相同交付键不同规范化内容仍拒绝为冲突。
- [ ] 选择未知平台、视频号图文、首版平台预约等不支持组合时提前返回 unsupported，不能改成立即发布。
- [ ] 账号引用必须指向已登记的预期账号；本地显式素材选择保持支持，外部清单不能通过账号名或素材引用越过声明的信任边界。
- [ ] 从公共入队/运行/查询接口验证失败阶段和字段错误，断言实际交付次数为 0，而非只测试验证 helper。

**测试边界:** 以已经确认的公共 CLI/任务接口为主；只有平台页面、进程终止和资源回收等必要场景增加本地测试。验收观察结果与交付行为，不绑定私有实现细节。
