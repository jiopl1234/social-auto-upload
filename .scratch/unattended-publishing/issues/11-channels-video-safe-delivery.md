# 11 — 视频号视频正确处理声明、实名验证和发布状态

**What to build:** 使用者发布视频号视频时，系统准确设置内容与声明，实名验证出现即停止；只有可靠作品证据才能报告已发表。

**Blocked by:** 04 — 发布前验证不可变清单、素材版本和声明事实；06 — 任务超时或取消后准时退出，并释放浏览器资源

**Status:** in-progress

**来源:** 《三平台个人账号无人值守发布》规格；用户故事 8、11、12、13、14、15、16、17、22、24、25、26、27、31、32、38；代码审计需求 R02、R03、R05、R06、R07、R10。

- [ ] 接入开始核查视频号稳定账号 ID 与作品查询字段；空白页、错误壳页、过晚出现登录框和账号不符均不通过认证。
- [ ] 移除默认含 AI 生成内容和声明失败继续发的行为；需要设置的声明、封面、合集等按照清单应用并读回。
- [ ] 实名验证出现在任一阶段均有界返回并暂停账号，不等待管理员扫码；弹窗消失不自动等于验证成功。
- [ ] 删除常规 click 失败后 JS 再点、循环重新发表和全局删除未知浮层的行为。
- [ ] URL 离开编辑页、发表按钮消失、草稿页跳转均不单独作为已发布成功条件；审核中、草稿、拒绝及未知结果分别表达。
- [ ] 上传等待复用有界策略并区分处理失败、页面关闭、验证和网络问题；截止与关闭异常不丢失原始原因。
- [ ] 从公共任务接口验收延迟、断连、验证及 false-success 场景；视频号图文与平台预约请求继续明确拒绝。

**测试边界:** 以已经确认的公共 CLI/任务接口为主；只有平台页面、进程终止和资源回收等必要场景增加本地测试。验收观察结果与交付行为，不绑定私有实现细节。
