# 01 — 干净安装后可运行三平台 CLI，并恢复旧参数语义

**What to build:** 使用者按主线依赖安装并初始化配置后，可以运行三平台命令；已有命令与受支持的 Python 位置参数保持原意。先修当前可复现的安装、兼容和测试基线，再开始任务系统改造。

**Blocked by:** None — can start immediately

**Status:** draft — breakdown approved; pending tracker selection

**来源:** 《三平台个人账号无人值守发布》规格；用户故事 1、2、3；代码审计需求 R01。

- [ ] 全新隔离环境按声明依赖安装后，三平台帮助、参数解析与无账号检查均可运行；不因未使用平台缺少可选依赖而在 import 阶段失败。
- [ ] 抖音旧位置调用中的发布策略、debug、headless 仍绑定原值；新增合集参数用关键字传入，不能靠改测试期望接受错位。
- [ ] 配置初始化具有明确行为；缺账号时返回可理解的非零结果，不进入交互式登录。
- [ ] 修复现有过时 Namespace 和异步替身，使原测试确实到达目标行为；不通过删除用例或放宽关键断言制造通过。
- [ ] 现有测试全套通过，记录干净安装命令和结果；话题测试改为正确候选与正文不受损的行为验证。
- [ ] 非目标平台入口保持兼容；本票不引入持久任务或重写平台发布流程。

**测试边界:** 以已经确认的公共 CLI/任务接口为主；只有平台页面、进程终止和资源回收等必要场景增加本地测试。验收观察结果与交付行为，不绑定私有实现细节。
