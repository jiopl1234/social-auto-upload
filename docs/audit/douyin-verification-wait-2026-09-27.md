# 抖音发表后本人验证等待

基线：`a421e15`。规格：[本地任务](../../.scratch/douyin-verification-wait/spec.md)。使用方法：[抖音视频 CLI](../douyin-video.md#发表后保留验证窗口)。

## 实现范围

- `jobs run --job JOB_ID --headed --verification-wait 180` 显式开启，默认关闭，允许 1–600 秒；仅适用于尚未提交的单个抖音视频任务。
- 点击发表后，在等待回执、跳转前检查或独立作品核对中检测到验证时，立即持久化账号暂停与事件，stderr 提示，保留原浏览器和任务锁。
- 仅观察原提交，不再次点击发表，不填写验证码，不移除挑战或刷新页面。多次验证、跨阶段验证共享首次提示开始的单调时钟截止时间，仍受总期限、阶段预算、取消、所有权和清理预留约束。
- 验证后必须取得新的页面身份响应、同次提交回执、保存会话并重新检查，再独立核对作品。只有完整证据和无异常清理才能解除本次验证暂停。
- 旧 UNKNOWN_COMMIT 的原浏览器已经丢失，只能只读恢复；新选项不能让其重新发表。

## 真实平台边界

本次没有再次上传或公开发表 `1.mp4`、`2.mp4`，没有修改 `2.mp4` 原未知提交任务，也没有解除真实账号暂停。原任务仍应按原交付记录处理。

此功能尚未通过真实抖音验证窗口的完整续行验收。若页面验证完成后未产生新的身份响应，程序仍保守停止。`production_verified=false` 保持不变；小红书和视频号的现有能力限制未改变。
