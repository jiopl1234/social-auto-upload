## 实现范围

三条视频路径共用 BrowserDeliveryAdapter 和 DomPagePort；分别登记旧代码中可定位的编辑控件候选。每个尝试独立浏览器/页面端口，准备与提交前确认稳定账号，逐素材正向处理完成，精确字段和声明读回，单次提交后查询独立作品记录。已有 worker 持有 SUBMITTING 事务和恢复策略。

生产平台的稳定账号 ID、处理完成及作品详情证据尚未得到真实页面验证，默认端口为 restricted，CLI 在浏览器启动前返回 UNSUPPORTED。没有开启生产限制的命令行开关。合成 fixture 的证据读取器只能运行在本地来源，外部 HTTP 请求被拦截；它不是三个创作者后台 DOM 的复制或实测证据。抖音图文、小红书图文暂待 08、10 号票。

旧视频 upload 及直接最终发表流程删除循环点击、未知浮层移除、默认 AI/无条件转载和 URL 推断成功，改为明确迁移错误。构造器、旧参数解析保持原语义；不能凭旧参数推断缺失的内容事实或稳定账号绑定。手动登录/维护入口保留。旧视频号实名等待现在立即 AUTH_REQUIRED，不导出二维码，也不把弹窗消失当作验证成功。

14 的会话私有 ACL、原子替换、诊断白名单、按 job/attempt 生成的独立证据和明确清理入口见 `ticket14-evidence.md`。Root 将浏览器版本、能力版本、失败摘要接入证据引用；诊断落盘失败不覆盖原错误。保留策略是显式 `jobs prune-evidence` 删除超过 30 天的托管诊断，未安装后台定时任务。

## 独立审查修复

候选 `de4a80e` 完整测试为 263 passed / 20 subtests passed。Standards 提出 3 项、Spec 提出 2 项，复审前逐项修复：

- 已完成任务的 CLI run 直接返回持久结果，不受真实平台能力门槛影响；公共 CLI 先红后绿。
- 旧视频入口在租约、Cookie 检查、驱动启动之前拒绝迁移。公共入口及包装器 8 项先失败后通过，相关回归 63 项通过；登录/维护锁仍单独覆盖。
- 诊断白名单保留有界且固定字段名组成的 targets 索引路径，拒绝任意嵌套密钥字段；批量公共接口及诊断测试 40 项通过。
- 最终账号/挑战/内容读回放在 SUBMITTING 之前，提交入口只执行已准备的单次动作。保存后账号变化、标题变化、验证弹窗三个本地 DOM 场景均保持 NOT_SUBMITTED 和提交数 0。
- 浏览器运行诊断先保存在有界内存中；浏览器清理后才在受父进程监控的子进程写证据，预算不足则跳过并保留数据库错误。卡住及取消会终止并回收子进程，不覆盖原始业务错误。
- 补查发现会话原子写盘也能阻塞清理，慢写盘故障先复现浏览器未关闭。会话落盘改为同一可回收进程传输，凭据仅通过管道，受保护临时文件校验后原子替换。文件写入超时/取消保留旧会话并清理浏览器；子进程必须确认结束，无法确认终止则保留资源隔离。相关浏览器/诊断/预检测试 22 项通过。复审去除了启动会话子进程时额外的同步 PID 登记落盘：会话保存全过程已在持久 resources_started 保护内；父异常退出留下该阻断标记，子进程又独立监视父身份。只有确认子进程结束及全部浏览器资源关闭后才允许清除标记。
